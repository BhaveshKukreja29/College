Experiment No. 03
Design a Form Using GUI Components in Android Studio
Aim: 
To design and implement a simple Form interface using various GUI components in Android Studio.
Prerequisite:

Object Oriented Programming Language (Java)

Course Outcome: 
             
After successful completion of this experiment students will be able to develop and demonstrate mobile applications using various tools.
Software used: 
    • Android Studio
    • Java
    • Android SDK
    • Emulator or Android Device
Theory: 

Android Studio is the official IDE used for developing Android applications using Java and XML. In this program, a Login/Registration Form is designed to collect user details such as First Name, Last Name, Email, and Password, and to validate the entered data before proceeding further.
The user interface of the application is designed using an XML layout file (activity_main.xml). A LinearLayout with vertical orientation is used to arrange the GUI components in a sequential manner. Multiple EditText components are used to accept user input, where appropriate inputType attributes such as text, textEmailAddress, and textPassword ensure correct input formats. Two Button components, namely RESET and PROCEED, are provided to perform user actions.
The application logic is written in Java within the MainActivity class, which extends AppCompatActivity. The onCreate() method initializes the activity and connects the XML layout to the Java code using setContentView(). All GUI components are linked to their corresponding Java objects using findViewById().
Event handling is implemented using OnClickListener for both buttons:
    • The PROCEED button triggers a validation process through the CheckAllFields() method.

    • The RESET button clears all input fields by setting their values to empty strings.

The CheckAllFields() method performs input validation by checking whether any of the text fields are empty. If a field is found empty or if the password length is less than eight characters, an error message is displayed using the setError() method. This ensures that the user enters valid and complete information before proceeding.
A boolean variable is used to track the validation status. Only when all fields are correctly filled does the program allow navigation to another activity using an Intent, demonstrating basic activity transition in Android.
Android provides a rich set of GUI (Graphical User Interface) components such as TextView, EditText, Button, RadioButton, CheckBox, and Spinner to build interactive user interfaces.
A Form is used to collect user information like name, email, gender, and preferences. In Android, layouts such as LinearLayout or ConstraintLayout are used to arrange UI components.
GUI Components Used:
    • TextView – To display labels
    • EditText – To accept user input
    • RadioGroup & RadioButton – To select options
    • CheckBox – To select options
    • Button – To submit the form


Procedure:

    1. Open Android Studio.
    2. Create a new project → Select Empty Activity.
    3. Name the project as FormApp.
    4. Choose Java as the language.
    5. Open activity_main.xml.
    6. Add GUI components using XML.
    7. Open MainActivity.java.
    8. Write code to handle button click events.
    9. Run the application on an emulator or real device.
Tasks:
Design and develop an Android application using Android Studio to create a Login/Registration Form. The application should provide a user interface containing input fields for First Name, Last Name, Email, and Password, along with RESET and PROCEED buttons. The application must validate user input to ensure that no field is left empty and that the password contains a minimum of eight characters. Appropriate error messages should be displayed for invalid inputs. Upon clicking the RESET button, all input fields should be cleared. The application should allow navigation to the next activity only after successful validation of all input fields.
