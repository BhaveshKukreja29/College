Experiment No. 02
Implementation of Basic 3D Graphical Primitives
Aim: 
To design and implement basic 3D graphical primitives such as cube using Android Studio.
Prerequisite:

Object Oriented Programming Language (Java)

Course Outcome: 
             
After successful completion of this experiment students will be able to develop and demonstrate mobile applications using various tools.
Software used: 
    • Android Studio
    • Java
    • Android SDK
    • Emulator or Android Device
Theory: 

A Bitmap is created to act as a drawing surface. The bitmap is set as the background of an ImageView, allowing all graphical elements to be displayed on the screen. A Canvas object is then associated with the bitmap, which provides methods to draw shapes, lines, and text.
The Paint class is used to define drawing properties such as color and text size. Different Paint objects are used to distinguish between the cube and cuboid by assigning different colors. Using the drawLine() method, multiple straight lines are drawn to form the edges of the cube and cuboid. By offsetting the front and back faces and connecting corresponding vertices, a 3D effect is achieved on a 2D screen.
Text labels are added using the drawText() method to identify the cube and cuboid. The coordinates supplied to the drawing methods determine the position and dimensions of the shapes on the screen.
Thus, this program demonstrates how 3D primitives can be represented using 2D drawing techniques in Android utilizing the Bitmap, Canvas, and Paint classes.

Question of Curiosity: 
    1. What is the role of Bitmap in this program?
The Bitmap acts as your digital canvas or frame buffer. While the Canvas provides the "tools" (brushes, lines, shapes), the Bitmap is the actual memory space where the pixel data is stored. Once the Canvas finished drawing the 3D projection, the Bitmap holds the final flattened image to be displayed.

    2. How is the 3D effect achieved in this experiment?
The effect is achieved through Perspective Projection math. Since a screen is 2D, you calculate the "scale" of an object based on its distance (Z value) from the viewer.
    • Scaling: Points further away are moved closer to the center of the screen and drawn smaller.
    • Transformation: You map 3D coordinates (x, y, z) to 2D coordinates (x, y) using a projection ratio, creating the illusion of vanishing points.


    3. What is the function of ImageView in this program?
The ImageView is the UI container that bridges your background logic and the user's screen.
    • Because Canvas and Bitmap are just data in memory, they aren't visible by default.
    • You call imageView.setImageBitmap(yourBitmap) to push that rendered data into the Android View hierarchy so the user can actually see it.
