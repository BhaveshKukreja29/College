Aim:

Theory: 

2D graphical primitives are the basic building blocks used to create complex images and graphics.
 In Android, 2D graphics are drawn using the Canvas and Paint classes.
    • Canvas: Provides methods to draw shapes on the screen.
    • Paint: Defines color, stroke width, style, and text size.
Common 2D Primitives
    • Point is drawn using the drawPoint() method.
    • Line is drawn using the drawLine() method.
    • Rectangle is drawn using the drawRect() method.
    • Circle is drawn using the drawCircle() method.
    • Polygon is drawn using the drawPath() method.

Procedure:

    4. Create a custom View class.

MyView.java
package com.example.ritwik;

import android.content.Context;
import android.graphics.Canvas;
import android.graphics.Color;
import android.graphics.Paint;
import android.graphics.Path;
import android.view.View;

public class MyView extends View {

    Paint paint;

    public MyView(Context context) {
        super(context);
        paint = new Paint();
        paint.setAntiAlias(true);
        paint.setStrokeWidth(5);
    }

    @Override
    protected void onDraw(Canvas canvas) {
        super.onDraw(canvas);

        // Draw Point
        paint.setColor(Color.RED);
        canvas.drawPoint(100, 100, paint);

        // Draw Line
        paint.setColor(Color.BLUE);
        canvas.drawLine(150, 150, 400, 150, paint);

        // Draw Rectangle
        paint.setColor(Color.GREEN);
        paint.setStyle(Paint.Style.STROKE);
        canvas.drawRect(100, 200, 400, 350, paint);

        // Draw Circle
        paint.setColor(Color.MAGENTA);
        canvas.drawCircle(250, 500, 100, paint);

        // Draw Polygon (Triangle)
        paint.setColor(Color.BLACK);
        Path path = new Path();
        path.moveTo(100, 700);
        path.lineTo(300, 700);
        path.lineTo(200, 550);
        path.close();
        canvas.drawPath(path, paint);
    }
}

Observations:

The coordinate system on the Android screen originates at the top-left corner of the screen.

A single Paint object is initialised in constructor and reused for all shapes. By changing properties like setStyle and setColor dynamically within onDraw, we avoid memory overhead of creating objects for each shape.



Conclusions:
​In this experiment, we successfully demonstrated the printing of Hello World and fundamentals of 2D graphics rendering in Android using the Canvas and Paint classes. We observed that the onDraw() method acts as the primary entry point for rendering, where the Canvas provides the drawing surface and the Paint object controls stylistic properties such as color, style (stroke vs. fill), and stroke width.

Question of Curiosity: 
    1. What is the use of the Canvas class?
The Canvas class provides a drawing surface on which you can draw shapes, text, and images.

    2. How are polygons drawn in Android?
To draw polygons, you define a Path object with the polygon's vertices and then draw the path on the Canvas using a Paint object to specify color and style.

    3. What is the role of onDraw() method?
The onDraw() method is a callback where all your drawing commands are executed. Android calls this method whenever your view needs to be redrawn, and it passes a Canvas object for you to draw on.
