Theory:  

A macroprocessor is a system software component that allows programmers to define macros (a sequence of instructions) and reuse them multiple times in a program. When a macro is called, the macroprocessor replaces the macro call with the macro body. 

A Multi-Pass Macroprocessor processes the source program in two passes. 

Pass 1 

During Pass 1, the macro definitions are processed and stored in tables: 

    MNT (Macro Name Table) – Stores macro name and pointer to MDT. 

    MDT (Macro Definition Table) – Stores macro body. 

    ALA (Argument List Array) – Stores arguments used in macro. 

Tasks of Pass 1: 

    Identify MACRO and MEND statements. 

    Store macro name in MNT. 

    Store macro body in MDT. 

    Process formal parameters. 

Pass 2 

During Pass 2: 

    Macro calls are expanded. 

    Actual parameters replace formal parameters. 

    The final expanded assembly code is generated. 

Tasks of Pass 2: 

    Detects macro calls. 

    Refer to MNT to find the macro. 

    Fetch macro body from MDT. 

    Replace parameters using ALA. 

    Produce expanded source program.

Algorithm: 

Pass 1 Algorithm 

    Start. 

    Read the source program line by line. 

    If MACRO statement is encountered: 

    Read next line containing macro prototype. 

    Enter macro name in MNT. 

    Store macro body lines in MDT until MEND. 

    Continue reading program. 

    Store non-macro statements in an intermediate file. 

    Stop at the end of file. 

Pass 2 Algorithm 

    Start. 

    Read intermediate code line by line. 

    Check whether the statement is a macro call. 

    If macro call exists: 

    Search macro name in MNT. 

    Fetch macro definition from MDT. 

    Replace formal parameters with actual parameters using ALA. 

    Write expanded statements to output. 

    If not a macro call, copy the statement to output. 

    Repeat until the end of the file. 

    Stop. 

 

Procedure: 

    Write the source program containing macro definitions and macro calls in an input file. 

    Compile the C program for Multi Pass Macroprocessor using a C compiler. 

    Execute the program to start Pass 1 processing. 

    During Pass 1, the program reads the input file and identifies the MACRO and MEND statements. 

    Store the macro name in the Macro Name Table (MNT) and the macro body in the Macro Definition Table (MDT). 

    Generate an intermediate file that contains the source program without macro definitions. 

    Start Pass 2 of the macroprocessor. 

    Read the intermediate file line by line and detect macro calls. 

    Replace each macro call with the corresponding macro definition from MDT. 

    Display or store the expanded program as the final output. 

    Verify that all macro calls are correctly expanded. 

    Observe the generated MDT, intermediate code, and final expanded program. 

Tasks: 

    Write a program in C to implement a Two Pass Macroprocessor. 

    The program should read an assembly language source program containing macro definitions and macro calls. 

    In Pass 1, identify macro definitions and store them in the Macro Name Table (MNT) and Macro Definition Table (MDT) while generating an intermediate file. 

    In Pass 2, read the intermediate file and expand the macro calls by replacing them with the corresponding macro body from the MDT. 

    Display or generate the final expanded source program as output.
