Theory:  

An LL(1) parser is a top-down, predictive parser that: 

    L → Scans input from Left to right 

    L → Produces a Leftmost derivation 

    1 → Uses 1 lookahead symbol 

LL(1) parsing requires: 

    No left recursion 

    No left factoring ambiguity 

    Disjoint FIRST sets for productions 

    If ε (epsilon) is present, FIRST and FOLLOW must be disjoint 

Example of LL(1) Parsing Table Construction 

Given Grammar 

Consider the grammar: 

S → aA 

A → b 

Where: 

    Non-terminals: S, A 

    Terminals: a, b 

    Start symbol: S 

Step 1: Compute FIRST Sets 

    FIRST(S) = { a } 

    FIRST(A) = { b } 

Step 2: Compute FOLLOW Sets 

    FOLLOW(S) = { $ } (S is start symbol) 

    FOLLOW(A) = { $ } (A appears at end of S → aA) 

Step 3: Construct Parsing Table 

Create table M[A, a] for terminals {a, b, $}. 

Fill entries: 

    For S → aA 

    FIRST(aA) = { a } 
    → Put S → aA in M[S, a] 

    For A → b 

    FIRST(b) = { b } 
    → Put A → b in M[A, b]

Algorithm: 

    Input the grammar G = (V, T, P, S). 

    Compute FIRST sets for all non-terminals in V. 

    Compute FOLLOW sets for all non-terminals in V. 

    Add $ to FOLLOW(S). 

    Initialize the parsing table 

    Create table M[A, a] for all A ∈ V and a ∈ T ∪ {$}. 

    Set all entries to empty. 

    Fill the parsing table 
    For each production A → α in P: 
    a) For every terminal a ∈ FIRST(α) (except ε), 
    → Put A → α in M[A, a]. 
    b) If ε ∈ FIRST(α), 
    → For every terminal b ∈ FOLLOW(A), 
    Put A → α in M[A, b]. 

    Check for conflicts 

    If any table entry contains more than one production, 
    → Grammar is not LL(1). 

    Otherwise, 
    → Parsing table constructed successfully.
