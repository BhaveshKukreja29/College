Theory: 
An Assembler is a system software that translates an assembly language program into machine language.
Two Pass Assembler
A two pass assembler works in two phases:
Pass I
    • Scans the program.
    • Assigns addresses to symbols.
    • Generates:

        ◦ Symbol Table (SYMTAB)
        ◦ Intermediate Code (IC)
Pass II
    • Uses intermediate code and symbol table.
    • Generates final machine code.

Algorithm:
Pass I Algorithm
    1. Initialize Location Counter (LC).
    2. Read first instruction.
    3. If START, initialize LC.
    4. For each instruction:
        ◦ If label present → add to SYMTAB.
        ◦ Generate intermediate code.
        ◦ Update LC.
    5. Stop at END.
Pass II Algorithm
    1. Read intermediate code.
    2. Replace symbolic addresses using SYMTAB.
    3. Generate machine code.
    4. Output final object code.
Procedure:
    1. Open any C Compiler
        a. Use tools like Turbo C / Code::Blocks / GCC (Terminal) / Online Compiler.
    2. Create a New C File
        a. Write the program and save it as:
 assembler.c
    3. Write/Input the Assembly Program
        a. Store it in a file (e.g., input.txt) and read using file handling.
    4. Compile the Program
        a. If using GCC (terminal):
 gcc assembler.c -o assembler
    5. Run the Program
 ./assembler
 (On Windows: assembler.exe)
    6. Provide Input (if required)
        a. Enter assembly instructions manually or ensure input file is present.
    7. Observe Pass I Output
        a. Intermediate Code (IC)
        b. Symbol Table (SYMTAB)
    8. Observe Pass II Output
        a. Final Machine Code generation
    9. Verify Results
        a. Check correctness of:
            i. Addresses
            ii. Opcodes
            iii. Symbol resolution
    10. Save Output (Optional)
    • Store results in files like:
        ◦ ic.txt
        ◦ symtab.txt
        ◦ output.txt
Tasks:
    1. Develop a C program to implement a Two Pass Assembler.
    2. In Pass I:
        a. Read the assembly program.
        b. Maintain a Location Counter (LC).
        c. Generate Intermediate Code (IC).
        d. Construct the Symbol Table (SYMTAB).
    3. In Pass II:
        a. Read the Intermediate Code.
        b. Replace symbolic operands using SYMTAB.
        c. Generate final Machine Code.
    4. Display:
        a. Intermediate Code
        b. Symbol Table
        c. Machine Code
    5. Test the program using the given assembly input.
