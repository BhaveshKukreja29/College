Three Address Code Generation

To write a program for generating Three Address Code (TAC) from a given arithmetic expression.

Theory:  

Three Address Code (TAC) is an intermediate representation used in compilers during program translation. It breaks complex expressions into a sequence of simple instructions containing at most three operands. 

Each TAC instruction generally has the form: 

result = operand1 operator operand2 

or 

result = operator operand 

TAC helps in: 

    Simplifying expressions 

    Code optimization 

    Easy machine code generation 

Example 

Expression: 

a = b + c * d 

TAC: 

t1 = c * d 

t2 = b + t1 

a = t2 

Temporary variables (t1, t2, etc.) are used to store intermediate results. 

Algorithm: 

    Start the program. 

    Accept an arithmetic expression. 

    Scan the expression from left to right. 

    Identify operators based on precedence. 

    Generate temporary variables. 

    Convert each operation into TAC format. 

    Print generated Three Address Code. 

    Stop. 

Procedure: 

    Open the C programming environment. 

    Create a new file named tac.c. 

    Type the program. 
     

    Compile the program using the compiler. 

    Execute the program. 

    Enter an arithmetic expression. 

    Observe the generated Three Address Code. 

Tasks: 

Implement a C program that reads an arithmetic expression as input and generates its corresponding Three Address Code (TAC) by scanning the expression and identifying operators based on precedence. The program should create temporary variables (t1, t2, t3, etc.) to store intermediate results and print each operation in the form of result = operand1 operator operand2. During implementation, students must handle operators such as +, −, *, and /, update the expression step-by-step after each operation, and display the final TAC output clearly. The program should be compiled, executed with different test expressions, and verified for correct intermediate code generation.
