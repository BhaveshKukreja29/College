Theory:  

Code optimization is a compiler design technique used to improve the performance and efficiency of generated code without changing its output. One important optimization method is Common Subexpression Elimination. 

A common subexpression is an expression that appears more than once in a program and evaluates to the same value, provided the variables involved are not modified between occurrences. 

Example: 

t1 = a + b 

t2 = a + b 

t3 = t1 * c 

Here, a + b is computed twice. This is redundant. 

After applying Common Subexpression Elimination: 

t1 = a + b 

t2 = t1 

t3 = t1 * c 

Thus, repeated evaluation is avoided, improving efficiency. 

Common Subexpression Elimination reduces: 

    Execution time 

    Code size 

    CPU usage 

It is commonly applied on Three Address Code (TAC) during intermediate code optimization. 

Algorithm: 

    Input the intermediate code (Three Address Code). 

    For each expression: 

    Check if the same expression was previously computed. 

    Ensure none of its operands were modified after its first computation. 

    If found: 

    Replace the repeated expression with the previously computed temporary variable. 

    Generate optimized code. 

Procedure: 

    Open a C compiler (e.g., GCC / Turbo C). 

    Type the program for common subexpression elimination. 

    Compile the program. 

    Execute the program. 

    Enter two expressions to check for redundancy. 

    Observe the optimized output. 

Sample Input 

Enter first expression: a+b 

Enter second expression: a+b 

Sample Output 

Common Subexpression Found! 

Optimized Code: 

t1 = a+b 

t2 = t1
